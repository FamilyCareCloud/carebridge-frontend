# 케어브릿지 화면

로그인 후 **케어브릿지** 메뉴에서 사용할 수 있다. 기존 인증·그룹 선택과 같은 백엔드를 이용한다.

- 메모 작성: 가상·비식별 확인, 입력 언어 선택, 텍스트·음성·음성 파일 입력
- 전사 확인: 최대 30초 음성을 텍스트로 먼저 확인·수정한 뒤 초안 생성
- 검토함: 원문·한국어 번역·관찰·원문 인용·QA 보류 사유를 분리해 표시
- 수정/검토: 수정 사유, 원문 대조·추가확인, 담당자 승인 또는 보류
- 이력: 변경자·시간·사유·불변 버전 열람. 과거 버전에서 승인할 수 없음
- 가족 미리보기: 승인된 현재 버전의 관찰 문장만 수동 열람
- 역할 설정: 그룹 소유자가 보호자를 작성자·검토자·가족으로 지정

내가 작성한 메모, 저장하지 않은 수정, QA 보류, 원문 확인 미완료 상태에서는 승인 버튼이 막힌다.
서버가 권한·버전·승인 여부를 다시 검사하므로 화면 버튼만 신뢰하지 않는다.
수정/재검사 후에는 가족 미리보기가 닫히며, 재승인이 필요하다.
API 충돌·장애 때 입력과 수정 사유를 보존한다. 페이지를 벗어나면 진행 중 마이크를 중지한다.
초안/원문은 브라우저 영구 저장소에 저장하지 않는다.

## 실행·검증

세 저장소를 같은 부모 폴더에 두고 백엔드의
[시작/중지·역할별 로컬 데모·AWS 설정 안내](https://github.com/FamilyCareCloud/fcc-backend/blob/feature/carebridge-workflow/docs/CAREBRIDGE.md)를 따른다.
AI GPU 기능은 fcc-ai PR #4 이후 버전이 필요하다.

로컬 프론트는 Vite의 VITE_DEV_PROXY_TARGET을 http://127.0.0.1:3002로 지정하고,
VITE_API_BASE_URL은 비우거나 /로 지정한다. AI 주소/서비스 키를 프론트 변수에 넣지 않는다.
서비스 주소는 기본 http://127.0.0.1:5174 이다.

```text
npm ci
npm run lint
npm test
npm run build
```

GitHub PR 검사와 Amplify 빌드에 화면 동작 테스트를 포함했다.
테스트는 가족의 원문 API 호출 차단, 비식별 확인, 원문 대조/사유/저장 안 한 수정에 따른 승인 제한,
자가 승인 제한, 충돌 시 입력 보존, 마이크 해제를 확인한다.
실제 브라우저의 시각 점검은 도구가 URL을 확인하지 못해 중단했으며, 스크린샷 검증으로 보고하지 않는다.
이 기능은 교육용 합성 시나리오이며 번역·현장·임상 정확도 검증이 아니다.
