# 화면 언어

로그인·회원가입과 작업 화면은 한국어(`ko`), 영어(`en`), 베트남어(`vi`), 인도네시아어(`id`)를 지원한다. 기본값은 한국어이며 각 언어는 선택 메뉴에서 자국어 이름으로 표시한다.

- `src/workspace/locales.json`: 한국어 원문을 키로 사용하는 화면 번역. 변수는 `{name}`, `{count}`처럼 명명하며 번역에도 같은 변수를 유지한다.
- `src/workspace/i18n.ts`: 언어 설정, 화면 구독, 문구 보간. `carebridge.ui-language.v1` 키로 브라우저에 저장한다. 저장소 접근이 거부되면 현재 페이지 메모리에서 동작한다.
- `src/workspace/LanguageSelector.tsx`: 로그인·헤더의 언어 선택과 오류 표시. 선택 시 새로고침이나 서버 요청 없이 문구만 갱신한다.
- 날짜는 동일한 원본 시각을 선택한 언어의 `Intl.DateTimeFormat`으로 표시한다. 표시 시간대는 기존 브라우저 시간대를 유지한다.

화면 언어는 작성 언어와 독립적이다. 사용자가 입력한 원문·초안·검토 내용·공개문, 이름, 기관명, AI가 반환한 검사 내용, 저장된 이력의 상세 원문에는 `t()`를 적용하지 않는다. 서버 오류 중 등록된 문구는 번역하고, 미등록 오류는 번역된 공통 안내와 **원본 오류**를 함께 표시한다. 브라우저 자체의 새로고침 경고와 기본 입력 검증 문구는 브라우저 언어를 따른다.

신규 화면 문구는 `t()`로 표시하고 세 번역을 함께 추가한다. 언어 전환으로 입력값·선택·페이지 이력을 초기화하거나 컴포넌트의 key를 바꾸지 않는다. `tests/workspace-locale.test.tsx`는 입력 보존, 작성 언어 독립성, 설정 복원, 날짜 표시, 오류 원문 유지와 정적 키·변수 누락을 확인한다.
